The Sunflower Theory - a website made for Lola

Open index.html in any browser (double-click it). Keep the assets/ folder next to it.

Files
  index.html       All the HTML, CSS and JavaScript.
  assets/sun.mp4   The original video.
  assets/*.webp    Stills taken from the video (day, night, bouquet).

Easy edits in index.html (use your editor's search)
  The love note:        search for  There are a hundred ways to say it
  The sign-off:         search for  Always yours   (add your name, e.g. "Always yours, Sam")
  Her name:             search for  Lola
  Colors:               the :root block at the top of the <style> tag

To host it, upload the whole folder to any static host (Netlify, GitHub Pages, Vercel, etc.).
